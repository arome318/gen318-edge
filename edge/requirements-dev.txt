# suite never exercises and that make CI slow or fragile —
#   sqlcipher3  needs the libsqlcipher-dev system package; EdgeDatabase
#               falls back to stdlib sqlite3 when no encryption key is
#               set, which is how the tests run.
#   xgboost     installed below as the small CPU-only build (xgboost-cpu),
#               because the site-learning tests train real models.
# Runtime pins below mirror requirements.txt — keep them in step.
